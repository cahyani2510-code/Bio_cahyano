# Portfolio Raka Pratama

Template portfolio kreatif berbasis React dan Vite. Tidak menggunakan library ikon; ikon panah dibuat dengan SVG inline. Foto contoh dan font DM Sans/DM Serif Display dimuat dari Unsplash dan Google Fonts.

## Menjalankan lokal

```sh
npm install
npm run dev
```

## Build dan lint

```sh
npm run lint
npm run build
```

## Menyesuaikan konten

- Ubah nama, bio, kontak, dan bagian portfolio di `src/App.jsx`.
- Daftar proyek, kategori, deskripsi, dan gambar ada di konstanta `projects` pada file yang sama.
- Ganti URL foto Unsplash dengan gambar milik sendiri untuk penggunaan produksi.
- Warna, layout, dan breakpoint responsive ada di `src/App.css`; gaya dasar dan font ada di `src/index.css`.

Fitur interaktif mencakup navigasi mobile, tema terang/gelap, filter dan modal proyek, unduhan resume teks, serta salin email.
